> - 提供快速的搜索响应时间。
> 
> **使用场景**:
> - 产品搜索：用户可以通过关键词搜索产品。
> - 日志分析：对系统日志进行实时分析和查询。
> 
> **索引设计**:
> ```json
> PUT /products
> {
>   "mappings": {
>     "properties": {
>       "product_id": { "type": "keyword" },
>       "name": { "type": "text" },
>       "description": { "type": "text" },
>       "price": { "type": "double" },
>       "category": { "type": "keyword" },
>       "created_at": { "type": "date" }
>     }
>   }
> }
> ```
> 
> **数据同步方式**:
> - 使用Logstash从数据库同步数据到ES。
> - 使用Elasticsearch的Bulk API进行批量数据导入。
> - 实时数据更新通过应用程序直接写入ES。
